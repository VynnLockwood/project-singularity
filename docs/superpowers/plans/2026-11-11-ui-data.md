# UI rework 2b: the Data tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Data tab gets a database/table picker with a shareable address, a visible filter and sort bar, the grid in the new look, and a CSV export of the whole filtered view.

**Architecture:** Backend: the where/order logic in `read_rows` moves into one helper that a new streaming CSV endpoint also uses. Frontend: pure address helpers (`lib/dataRoute.ts`), `TablePicker`, `FilterBar`, a `GridEditor` whose view state (`sort`, `dir`, `filters`, `inactive`) comes in and goes out through optional props (backward compatible), and a `DataView` that owns the address. No router library; the address is the History API through the existing `navigate`.

**Tech Stack:** Django (one view, one helper, stdlib `csv`), Next.js 15 / React 19, vitest + Testing Library. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-11-ui-data-design.md`

## Global Constraints

- CSV: UTF-8 with BOM, header row, RFC 4180 quoting, `\r\n` line ends, NULL is an empty field.
- CSV text values starting with `=`, `+`, `-`, `@`, tab or CR get a leading `'`; numeric and boolean columns are never altered.
- CSV cap is `limits.maxExportRows`; over it: 400 `"{N} rows match; the most that can be exported is {M} (setting limits.maxExportRows). Narrow the filters."`; never truncate silently.
- CSV needs the editor role (viewer 403); one `table.export_csv` audit entry; filename `<schema>-<table>-<YYYY-MM-DD>.csv`; `Cache-Control: no-store`.
- Reference columns export raw ids, not labels.
- Address: `/data/<db>/<table>?sort=&dir=&inactive=1&f.<column>=<text>`. Page and page size are NOT in the address. Junk values mean "none".
- Filters mean case-insensitive contains, combined with AND (what the server does today).
- `GridEditor` props stay backward compatible: with no view props it behaves as today.
- Every existing test keeps passing; the only allowed test change is the GridEditor filter-row locator (see Task 5).
- Commit messages end with the two trailer lines the session attribution reminder gives.

## Review Focus

1. A column or filter text with `%`, `_`, quotes, commas, newlines or Thai text must export and round-trip exactly (and a filter must still match literally). (Task 1)
2. A cell like `=HYPERLINK(...)`, `+1`, `-x`, `@SUM` in a text column is prefixed; the number `-5` in a numeric column is not. (Task 1)
3. A hand-edited address (`?sort=nope&dir=up&f.x=1&inactive=2`, repeated keys, an unknown table) must show "none"/an inline message, never crash or send junk to the server. (Tasks 2, 6)
4. Changing a filter or sort while edits are pending must keep the edits and the Save bar count; a slow reply for an old view must not overwrite the current rows. (Task 5)
5. An export over the cap or an export error shows the server's message and does not navigate away or download a partial file. (Tasks 1, 5)
